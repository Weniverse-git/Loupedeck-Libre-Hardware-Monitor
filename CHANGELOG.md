# Changelog

## [1.1.0] - 2025-01-28

### Added
- Temperature threshold arcs on all gauge views (Green/Yellow/Red color indicators)
- Faded background (30% opacity) on all block views for better visual feedback

### Changed
- CPU block color changed from green to gray
- GPU VRAM block color changed from light blue to purple

## [1.0.0] - 2025-01-27

### Added
- Initial release
- CPU temperature, load, power monitoring
- GPU temperature, load, power, VRAM monitoring
- RAM temperature, usage monitoring
- NVMe 0-4 temperature monitoring
- Gauge view for temperatures
- Block view for load percentages
- Total block view (4-row combined display)
